# Banana microbiome

This repository accompanies the manuscript "Organic amendments drive bacterial and fungal soil microbiomes over time in a subtropical banana agroecosystem"

Authors Raquel Correa-Delgado, Ignacio Romero-Lozano, Sonja Reinhardt, Maria del Carmen Jaizme-Vega, Federico Laich and Natacha Bodenhausen.
